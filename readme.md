## Phone Parser

Простая утилита для извлечения, проверки и дедупликации мобильных номеров России из текстовых файлов. Программа читает все .txt файлы из папки base, находит в них номера, отбирает только валидные мобильные (по кодам операторов РФ) и сохраняет уникальный отсортированный список в CSV.

## Как пользоваться

**Шаг 1**. Создайте рядом с программой папку с именем base (строчными буквами), если её нет

📁 phone_parser

├── phone_pars.py

└── 📁 base

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; &nbsp;└──  номера.txt

**Шаг 2**. Перенесите номера из Excel в текстовый файл

- Откройте Excel с таблицей, где есть столбец с номерами.

- Выделите нужный столбец с номерами и скопируйте его (Ctrl + C).

- Откройте «Блокнот» (или любой текстовый редактор) и вставьте содержимое в файл номера.txt внутри папки.


**Шаг 3**. Запустите программу phone_pars.py

Внутри папки base появиться готовый Excel файл с обработанными номерами

## Требования для запуска
